Bot bridge

The Chrome extension talks to the Docker bot over a local WebSocket. Both must agree on a URL and a shared token.

Default: ws://127.0.0.1:8787 — works for the standard docker compose up setup on Mac, Windows and Linux. (The compose file publishes 8787 to 127.0.0.1; check docker compose ps if in doubt.)
Must match XBOT_BRIDGE_TOKEN in bot/.env. Note: removing and re-loading the extension wipes this — you'll need to paste it again.
